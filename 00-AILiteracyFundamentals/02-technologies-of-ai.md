<summary> 🪣 <b>Supervised Classification Process</b> </summary>
1. Collect and prepare data (e.g., images labeled as “cat” or “dog”). <br>
2. Split the data into training data and test data. <br>
3. Train the model: the model learns patterns from the training data by mapping inputs to the correct labels using supervised learning. <br>
4. Test the model: the trained model is given unseen test data to make predictions. <br>
5. Evaluate performance: compare the model’s predictions with the true labels to measure accuracy. <br>
6. Use the model: once trained and evaluated, the model can classify new, unseen inputs (e.g., labeling an unlabeled image as “dog”). <br>
</details>
